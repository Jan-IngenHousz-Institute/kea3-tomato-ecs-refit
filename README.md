# KEA3 tomato drought trial: ECS re-fit

Analysis code behind Figure 4 of von Bismarck et al., *Experimental and computational analysis of KEA3 function in
the vegetable crop tomato compared with Arabidopsis* (in preparation).

The MultispeQ Photosynthesis RIDES 2.0 measurements are hosted on openJII:
[KEA3 tomato drought trial (MultispeQ, RL3)](https://openjii.org/en-US/platform/experiments/e0acb807-5a1a-4f35-8902-a1d8629d4cc9).
For this dataset the PhotosynQ macro's exponential fit of the 520 nm electrochromic shift (ECS) decay does not hold up,
so ECSt and gH+ are re-fitted from the raw traces here.

`notebooks/original/` holds the original analysis notebook by Thekla von Bismarck, unchanged.
